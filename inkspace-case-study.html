The Challenge

Traditional digital handwriting apps like GoodNotes and Notability are locked into the Apple ecosystem, leaving Android, Web, and Desktop users with fragmented, high-latency alternatives that lack real-time multi-device cloud synchronization.

lightbulb

The Solution

Inkspace Notebook delivers an uncompromised zero-latency digital notebook experience across Android, iOS, Web browsers, and Desktop from a single shared Kotlin codebase—featuring GPU-accelerated Skiko vector handwriting, time-stamped audio sync, multi-tab document management, and Supabase offline-first cloud synchronization.

System Architecture

palette

🎨 Shared UI Layer (Compose Multiplatform)

100% declarative UI sharing across all targets. Adaptive layout engine dynamically switching between mobile bottom navigation, tablet split-screen, and desktop collapsible sidebars.

⚡ Real-Time Inking Engine (Skiko & Canvas)

Bi-directional real-time cloud synchronization with row-level security, optimistic UI updates, and automated 3-way conflict resolution for multi-device concurrent edits.

Engineering Deep-Dives

01. Sub-8ms Inking Latency on Mobile & Web

Standard touch event dispatch loops introduce noticeable inking lag (20–40ms). Inkspace Notebook employs Skiko GPU hardware acceleration combined with quadratic Bézier curve interpolation that computes velocity-dependent stroke thickness and dynamic tail tapering directly on the GPU render thread.

// Quadratic Bézier Path Interpolation with Velocity Tapering
val midX = (prevPoint.x + currentPoint.x) / 2f
val midY = (prevPoint.y + currentPoint.y) / 2f
skikoPath.quadTo(prevPoint.x, prevPoint.y, midX, midY)
val dynamicWidth = computeTaperWidth(velocity, pressure)

02. 3-Way Offline Conflict Resolution

To prevent data loss when notes are edited simultaneously offline across tablet and desktop, vector stroke deltas are stamped with UUIDs and logical Lamport clocks. Reconnection triggers an automated 3-way merge that preserves non-overlapping strokes seamlessly.

view_quilt

03. Responsive 3-Tier GoodNotes Toolbar

GoodNotes 5 features 15+ navigation actions and 11 inking tools. On mobile screens (360dp–410dp), desktop-wide toolbars cause severe clipping. The responsive 3-zone header dynamically collapses Tier 1 into essentials, while Tier 3 features smooth 60fps horizontal swiping across all 11 tools and 8-color preset dots.
